# Identidad visual

logo_naruto.jpg es la imagen original proporcionada por el usuario.
appimage/un5-netplay.png es la conversión cuadrada de 512 px, conservando
la imagen completa y el fondo negro. Se usa para el icono y la cabecera de PC,
los iconos de Windows generados por su constructor y el APK Android.
mobile/prepare.py copia el PNG al paquete y buildozer.spec lo usa como icono.
